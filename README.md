# 🚀 Git Simulator Game

![Git Simulator Hero](/Users/petchauisui/.gemini/antigravity/brain/792e0300-ebe0-4234-bf01-7013436d2007/git_game_mockup_1776663058887.png)

Welcome to **Git Simulator**, an interactive, story-driven web application designed to help developers master Git through gamification. Step into the shoes of a new developer and complete missions given by your Boss to learn the core workflows of Git!

## ✨ Features

- 🎮 **Interactive Storyline**: Follow a narrative where every Git command you learn helps you progress in your career.
- 💻 **Real Terminal Experience**: Practice in an emulated terminal that validates your Git knowledge in real-time.
- 📊 **Visual Git Graph**: See your branches, commits, and merges come to life with a dynamic Git graph.
- 📁 **Virtual File System**: Interact with a virtual workspace to see how Git tracks your files.
- 🏆 **15 Educational Levels**: From basic configuration to advanced merging and remote operations.

## 📚 Curriculum

The game covers the following Git essentials:

1.  **Basics**: `version`, `config`, `init`
2.  **Tracking**: `status`, `add`, `commit`
3.  **Inspection**: `log` (oneline, graph, all)
4.  **Undo & Recovery**: `restore`, `reset` (--soft, --mixed, --hard)
5.  **Branching**: `branch`, `switch`
6.  **Merging**: `merge`, `abort`
7.  **Remote**: `clone`, `pull` (--rebase), `push` (-u, -f)

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: CSS Modules
- **State Management**: Custom React Hooks

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/PetchAuisui/game-based-git-learning.git
    cd game-based-git-learning
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    ```

4.  **Open the app**:
    Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
